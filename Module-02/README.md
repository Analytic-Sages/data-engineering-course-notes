# Module 02: Blockchain Data Warehousing and Indexing

In this module, we set up a dedicated PostgreSQL data warehouse and configure custom blockchain indexers to stream live ledger data.

---

## Core Concepts Covered in this Module

### A. Data Warehousing with PostgreSQL
* Structuring PostgreSQL as an analytical data warehouse.
* Optimizing schemas and configurations to store large-scale transactional blockchain event logs.

### B. Live Blockchain Indexing (Envio Indexer)
* Configuring the Envio indexer to track smart contract event logs on EVM-compatible chains.
* Defining event schemas, handler scripts, and indexing configurations to capture real-time `Transfer` events.
* Loading the structured, indexed event streams directly into our database tables.
